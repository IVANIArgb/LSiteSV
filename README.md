# LearningSite — учебный портал

Демонстрационный LMS для защиты проектной деятельности: курсы, уроки и тесты.
Контент лежит в файлах, база — для пользователей и прогресса.

## Установка (один установщик)

Скопируйте папку проекта учителю и запустите:

- **Windows:** дважды щёлкните `Установить.bat` (откроется терминал).
- **Linux / macOS:** в терминале `chmod +x install.sh && ./install.sh`.

Установщик покажет условия использования, спросит согласие на установку Python и библиотек, предложит папку (по умолчанию рабочий стол / `LearningSite`), поставит зависимости, предложит запустить сайт и создать на рабочем столе файлы **запуска** и **остановки** сервера.

После запуска откройте в браузере: http://127.0.0.1:5000

Учебный режим (`TEST_MODE`) входит как демо-администратор `testadmin`.

## Ручной запуск после установки

В папке проекта:

```text
.venv\Scripts\python run.py          (Windows)
.venv/bin/python run.py              (Linux/macOS)
```

Или скрипты в `start/start_server.py` и `start/stop_server.py`.

## Структура

- `frontend/` — страницы пользователя и администратора
- `backend/` — API и сервер
- `database/` — модели и SQLite
- `categories-data/` — учебный контент (создаётся при первом запуске / seed)

## Разработка

```text
.venv/Scripts/python -m pytest tests
```
